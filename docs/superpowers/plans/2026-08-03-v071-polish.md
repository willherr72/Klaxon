# v0.7.1 Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Peers exchange app versions (backward compatibly) with stale/outdated warnings, plus what's-new card, first-run card, README rewrite, and lint/a11y cleanups — shipped as v0.7.1 via the in-app updater.

**Architecture:** New trailing `Hello` variants on the existing postcard RPC enums (old peers lose one stream, never the connection); migration 012 adds `peers.last_app_version`; everything user-facing is Svelte with device-local settings keys. No new dependencies.

**Tech Stack:** Rust (postcard RPC over iroh), rusqlite migration, Svelte 5 runes, vite `?raw` import.

## Global Constraints

- `Hello` variants must be **trailing** in `RpcRequest`/`RpcResponse` — reordering existing variants breaks the wire.
- Hello failure (decode error / reset / 3 s timeout) records NULL and must never fail the sync pass.
- Stale warning threshold: 72 h. Outdated = peer version semver-older than ours; newer shown without alarm.
- Settings keys (device-local, never synced): `last_seen_version`, `onboarding_dismissed`.
- First-run card copy mentions the capture hotkey on desktop only.
- README screenshot slots: `docs/screenshots/desktop-main.png`, `phone-main.png`, `tasks-board.png` (user-provided later; text ships first).
- Zero cargo warnings; svelte-check 0 errors and (post-cleanup) 0 warnings.
- Branch: `feat/v0.7.1-polish` off main.

```rust
/// Version exchange. `Ok(None)` = the peer predates Hello (decode
/// failure/reset/timeout on its side or ours) — never an error, the
/// sync pass continues regardless.
pub async fn hello(
    endpoint: &Endpoint,
    node_id: &str,
    seed_addrs: &[TransportAddr],
    shared_secret: &str,
) -> Option<String> {
    let req = RpcRequest::Hello { app_version: env!("CARGO_PKG_VERSION").into() };
    match tokio::time::timeout(
        std::time::Duration::from_secs(3),
        call(endpoint, node_id, seed_addrs, shared_secret, req),
    )
    .await
    {
        Ok(Ok((RpcResponse::Hello { app_version }, _))) => Some(app_version),
        _ => None,
    }
}
```

```ts
const STALE_MS = 72 * 60 * 60 * 1000;
function isStale(p: PeerView): boolean {
  return p.last_sync_ok_at != null && Date.now() - p.last_sync_ok_at > STALE_MS;
}
function parseSemver(v: string): [number, number, number] | null {
  const m = v.trim().replace(/^v/, "").match(/^(\d+)\.(\d+)\.(\d+)/);
  return m ? [+m[1], +m[2], +m[3]] : null;
}
function isOutdated(p: PeerView): boolean {
  if (!p.last_app_version || !appVersion) return false;
  const a = parseSemver(p.last_app_version);
  const b = parseSemver(appVersion);
  if (!a || !b) return false;
  return a[0] < b[0] || (a[0] === b[0] && (a[1] < b[1] || (a[1] === b[1] && a[2] < b[2])));
}
```

```ts
/// Pull one version's section out of CHANGELOG.md (Keep-a-Changelog
/// shape): from "## [x.y.z]" to the next "## [" heading. Returns the
/// body without the heading line, trimmed, or null when absent.
export function extractChangelogSection(
  changelog: string,
  version: string,
): string | null {
  const lines = changelog.split(/\r?\n/);
  const start = lines.findIndex((l) => l.startsWith(`## [${version}]`));
  if (start === -1) return null;
  let end = lines.length;
  for (let i = start + 1; i < lines.length; i++) {
    if (lines[i].startsWith("## [")) { end = i; break; }
  }
  const body = lines.slice(start + 1, end).join("\n").trim();
  return body.length ? body : null;
}
```
